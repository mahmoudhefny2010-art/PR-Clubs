## Fixes made in this review

- Added SQL/Azure handling for the public-data stream. Four triggers update
  public revision counters within the same transaction as the source write,
  including bulk operations and deletions. The stream compares only those
  counters on the server every three seconds. Browsers download changed lists
  only; unchanged lists remain in their persistent local cache. This preserves
  the browser behavior but uses different infrastructure from Mongo's native
  change streams.
- Included notification DDL in new empty-target schema generation and supplied
  an additive migration for older isolated SQL targets. Runtime readiness checks
  the revision row and all four enabled triggers.
- Closed a readiness bypass: a connection opened for migration with
  `readiness: false` must now pass runtime readiness checks before reuse by a
  normal runtime connection. Invalid migration state or missing notification
  triggers closes the pool rather than reporting a ready application.
- Added an opt-in real SQL integration test for revision increments, no-op
  statements, deletes and rollback. It uses a transaction and always rolls back.
