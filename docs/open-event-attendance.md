# Open event attendance

Club presidents and IT heads can open their event QR to all signed-in MIU students by enabling the “Allow all authenticated MIU students” option before creating the code. Existing member-only QR sessions stay member-only. Each scan remains a verified physical check-in and stores the student's profile fields plus the membership snapshot found in current club rosters and accepted applications.

PR, SSO, Dean, and the global administrator can start an MIU event session from `/pages/miu-attendance.html`. The existing MIU event must have attendance enabled and be scheduled for today. Starting a session requires an active Supervisor account email and an existing student or staff account email for the usher. The usher signs in, opens “Attendance usher task” from the account menu, accepts the task, and presents the rotating QR on the device where they first opened it.

After attendance ends, MIU check-ins enter the assigned Supervisor's queue. Supervisor approval forwards them to PR, then SSO, then Dean, matching the club attendance stages. A supervisor cannot review a session they created or operated. Open student attendance is a separate review group and a separate per-event Excel download at “Open event attendance”; each row says Member with the saved club names, or Non-member. The regular club member sheet excludes these open-student records.

No semester dates or attendance figures are generated by this feature. Existing event dates, event attendance settings, club rosters, accepted applications, student profiles, and dashboard accounts are the data sources.
